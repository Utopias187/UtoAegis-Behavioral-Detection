# Ownership and copyright

This document records the repository controls and the remaining steps for a
formal United States copyright registration. It is an engineering checklist,
not legal advice.

## Repository controls completed on 2026-10-22

- The main repository and all eleven milestone source repositories were made
  private after confirming that GitHub reported zero forks for each repository.
- A public `UtoAegis-Showcase` repository was created with portfolio
  documentation only and no implementation source.
- The main repository received the UtoAegis Proprietary Source License,
  copyright build metadata, a README ownership notice, and third-party notices.
- Each private milestone repository received the same proprietary source
  license without changing its historical milestone tag.

These controls provide notice and reduce future source exposure. They cannot
recall copies that someone may have made while a repository was public, and
they do not replace government registration or legal enforcement.

## Ownership review before filing

1. Confirm that Francisco Jaimes owns every human-authored contribution being
   claimed. Review any employment, university, sponsorship, or contractor
   agreement that could assign ownership to another party.
2. Preserve the Git history, signed milestone tags, development journal, design
   records, and dated releases as evidence of project development.
3. Exclude third-party packages and their source from the copyright claim.
   Their licenses are summarized in `THIRD-PARTY-NOTICES.md`.
4. Document how generative AI assisted development. Identify the human-authored
   architecture, requirements, selection, coordination, testing, review, and
   creative modifications. Do not claim purely AI-generated expression.
5. Obtain a written ownership or assignment agreement before accepting any
   future contribution from another person.

## Registration checklist

1. Choose the exact version being registered and preserve an immutable copy.
   Commit `8260ab3` is the first main-repository version carrying the explicit
   proprietary notices; later code can be registered as an updated version.
2. Determine the work's publication status and the legally correct first
   publication date. The source was previously visible through public GitHub
   repositories, but whether a particular online release constitutes
   publication should be confirmed for the application.
3. Use the U.S. Copyright Office registration portal and select the application
   appropriate for a computer program.
4. Identify the human author and claimant accurately. Disclose and disclaim
   unprotectable third-party and AI-generated material as required, while
   describing the human-authored material being claimed.
5. Prepare the required source-code deposit using the Copyright Office's
   computer-program rules. Review the available trade-secret redaction options
   before submitting confidential source.
6. Pay the filing fee, certify the application personally, retain the submission
   receipt, and store the registration certificate with the private project
   records when issued.
7. Ask an intellectual-property attorney to review the proprietary license,
   ownership chain, AI disclosure, publication analysis, and registration
   application before commercial launch.

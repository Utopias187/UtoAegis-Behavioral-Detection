# Security policy

## Supported code

Only the current `main` branch is maintained. The milestone repositories are
historical snapshots and do not receive security fixes independently.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, discussion, or
social-media post. Contact the repository owner privately through the
[@Utopias187 GitHub profile](https://github.com/Utopias187) and include:

- the affected version or commit;
- the relevant component and configuration;
- reproducible steps or a minimal proof of concept;
- the expected and observed security impact; and
- any suggested mitigation, if known.

Do not include live malware, credentials, personal data, or secrets. Use inert
test material and redact sensitive values. Please allow time to reproduce,
assess, and correct the report before publishing details.

## Scope and safe testing

Testing is authorized only on systems and files you own or have explicit
permission to assess. Do not perform denial-of-service testing, access another
person's data, or weaken an endpoint's protections. This policy does not grant
permission to use or redistribute the proprietary source code; `LICENSE`
continues to govern all use.
